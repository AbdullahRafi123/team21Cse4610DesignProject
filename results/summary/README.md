# Collected summaries

Run `python scripts/collect_results.py` to rebuild combined CSV summaries and
plots from active experiment logs. The script regenerates outputs in this
directory; do not edit generated metrics by hand.

Collected outputs are convenient indexes, not substitutes for per-run
provenance. Interpret the October 2026 comparison using
[its exploratory analysis](../../docs/EXPERIMENT_ANALYSIS_2026-10-10.md), and
follow the [research standards](../../docs/RESEARCH_STANDARDS.md) before using
summaries as reported evidence.
